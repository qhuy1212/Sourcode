# UrbanThread Men’s Fashion Website

This project is a responsive online sales website built using HTML5, CSS3, JavaScript, Bootstrap, and localStorage.

## Included Pages
- `index.html` — Home page with featured products and add-to-cart functionality.
- `contact.html` — Contact page with form validation and localStorage saving.
- `login.html` — Login page with form validation and localStorage user authentication.
- `register.html` — Register page with form validation, account creation, and localStorage.
- `profile.html` — Profile page that displays user details and allows editing.
- `cart.html` — Shopping cart page with quantity updates, removal, and checkout.

## How to Use
1. Open `index.html` in a browser to view the website.
2. Register or login to save your profile information locally.
3. Add products to the cart and manage them from `cart.html`.
4. Contact form messages are saved to localStorage for demo purposes.

## Deploy to GitHub Pages
1. Create a GitHub repository and push all files from this folder to the repository root.
2. In the repository settings, enable GitHub Pages from the `main` branch (or `gh-pages` branch) and set the source to `/ (root)`.
3. Your site will be available at `https://<your-username>.github.io/<repository-name>/`.

## Notes
- No subfolders are used; all pages and assets are stored in the project root.
- The website uses browser localStorage for user sessions, cart persistence, and contact messages.
